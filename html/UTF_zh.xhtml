非官方 Texinfo 格式

这是第二版SICP书，
来自非官方 Texinfo 格式。

你很可能正在一个 Info 超文本浏览器中阅读它，例如 Emacs 的 Info 模式。你也可能在屏幕或打印机上阅读它的 TeX 格式版本，尽管那样做很傻。而且，如果打印出来，还很贵。

自由分发的官方HTML与GIF格式，最初由 Lytha Ayth 于2001年四月一个尽情享用 Emacs 的漫长周末，亲自转换成非官方 Texinfo 格式（UTF）第1版。

UTF比HTML格式更容易搜索。对于使用配置不高的计算机（例如捐赠的基于386的 PC）的人来说，它也更容易访问。一台386理论上可以同时运行 Linux、Emacs 和一个 Scheme 解释器，但大多数386大概也无法同时运行 Netscape 和必需的 X Window 系统，而不提前把抖动的概念介绍给初出茅庐、资金不足的年轻黑客们。UTF还可以未压缩地放在一张1.44MB软盘上，这可能便于在没有互联网或LAN访问的 PC 上安装UTF。

转换为 Texinfo 时，已尽可能采用直接转写的方式。与从 TeX 转换为HTML时一样，这一过程也难免造成一些损坏。在非官方 Texinfo 格式中，插图经历了一次对ASCII这门失传艺术的业余复兴。此外，在转换大量上标（‘^’）和下标（‘_’）中的某些部分时，很可能引入了一些歧义错误。至于推断哪些地方出了问题，就留作读者的练习了。不过，至少我们没有把大于等于符号编码成<u>&gt;</u>，让勇敢的宇航员置身险境。

如果你修改sicp.texi以纠正错误或改进ASCII艺术，那么更新@set utfversion 2.andresraba6.6行以反映你的改动。例如，如果你从 Lytha 的版本1开始，而你的名字是 Bob，那么你可以将你的连续版本命名为1.bob1、1.bob2、……1.bobn。还要更新utfversiondate。如果你想在 Web 上分发你的版本，那么在文件或网页中嵌入字符串“sicp.texi”将使人们更容易通过 Web 搜索引擎找到它。

据信，非官方 Texinfo 格式符合慷慨自由分发的HTML版本的精神。但你永远不知道什么时候某人的律师舰队可能需要找点事做，并因为一些无害的小事而大动干戈，所以在使用你的全名或分发可能嵌入你的账户或机器名的 Info、DVI、PostScript 或PDF格式之前，请三思。Peath, Lytha Ayth

补记：另见 Abelson 和 Sussman 的SICP视频讲座：在MIT CSAIL或MIT OCW。

第二次补记：以上是2001年对UTF的原始介绍。十年之后，UTF已经焕然一新：数学符号和公式得到了恰当的排版，插图也改用矢量图形绘制。原来的文本公式和ASCII字符画仍保留在 Texinfo 源文件中，但只有编译为 Info 输出时才会显示。随着电子书阅读器和平板电脑的兴起，在屏幕上阅读PDF正式不再是一件傻事了。祝阅读愉快！A.R，2011年五月

第三次补记：事物螺旋式发展。我们在排版PDF书时探索了 Texinfo 和 LaTeX 的能力。现在该回到HTML了。这一次将是HTML5。“这可能是一个危险的地方，但它是我们最后、最好的和平希望。”（Sinclair，Babylon 5。）浏览器大战之后和平能持续吗？无论如何，该项目的目标是通过使用HTML5工具箱来接近 LaTeX 输出的质量。这里使用了 JavaScript、CSS3、SVG、MathJax、MathML 和 Web 字体。由于这项工作的实验性质，在某些浏览器中会出现小故障和错误。感谢技术和艺术上的帮助。与此同时，尽情阅读这本书，并启动一个REPL！A.R，2014年一月
