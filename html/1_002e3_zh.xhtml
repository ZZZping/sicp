1.3用高阶过程构造抽象

我们已经看到，过程实际上是一种抽象，它描述了对数的复合操作，而不依赖于具体的数。例如，当我们

(define (cube x) (* x x x))

我们谈论的不是某个特定数的立方，而是获得任意数立方的一种方法。当然，我们完全可以不定义这个过程，而总是写出这样的表达式

(* 3 3 3)
(* x x x)
(* y y y)

并且从不明确提及cube。这会使我们处于严重的劣势，迫使我们始终在语言中恰好是基本操作（本例中是乘法）的层面上工作，而不是在更高层次的操作层面上工作。我们的程序能够计算立方，但我们的语言将缺乏表达立方概念的能力。我们应该要求一个强大的编程语言具备的能力之一是：通过为常见模式赋予名称来构建抽象，然后直接基于这些抽象进行工作。过程提供了这种能力。这就是为什么除了最原始的语言之外，所有编程语言都包含定义过程的机制。

然而，即使在数值处理中，如果我们局限于参数必须是数的过程，我们创建抽象的能力也会受到严重限制。通常，同一个编程模式会被用于许多不同的过程。为了将这类模式表达为概念，我们需要构造能够接受过程作为参数或返回过程作为值的过程。操作过程的过程称为高阶过程。本节展示高阶过程如何作为强大的抽象机制，极大地增强我们语言的表达能力。

1.3.1作为参数的过程

考虑以下三个过程。第一个计算从a到b的整数之和：

(define (sum-integers a b)
  (if (> a b) 
      0 
      (+ a (sum-integers (+ a 1) b))))

第二个计算给定范围内整数的立方之和：

(define (sum-cubes a b)
  (if (> a b) 
      0 
      (+ (cube a) 
         (sum-cubes (+ a 1) b))))

第三个计算级数 1 1 ⋅ 3 + 1 5 ⋅ 7 + 1 9 ⋅ 11 + … , 中一段连续项之和，该级数收敛到 π / 8 （非常缓慢）：49

(define (pi-sum a b)
  (if (> a b)
      0
      (+ (/ 1.0 (* a (+ a 2))) 
         (pi-sum (+ a 4) b))))

这三个过程显然共享一个共同的基本模式。它们大部分是相同的，区别仅在于过程的名称、用于计算待加项的、以a为自变量的函数，以及提供a下一个值的函数。我们可以通过填充同一模板中的空位来生成每一个过程：

(define (⟨name⟩ a b)
  (if (> a b)
      0
      (+ (⟨term⟩ a) 
         (⟨name⟩ (⟨next⟩ a) b))))

这种共同模式的存在有力地表明，有一个有用的抽象等待被揭示出来。事实上，数学家们很久以前就识别出了级数求和这一抽象，并发明了“sigma 记号”，例如 ∑ n = a b f ( n ) = f ( a ) + ⋯ + f ( b ) , 来表达这一概念。sigma 记号的力量在于，它允许数学家处理求和概念本身，而不仅仅是处理特定的和——例如，表述关于和的一般结果，这些结果独立于被求和的具体级数。

类似地，作为程序设计者，我们希望我们的语言足够强大，以便能够编写一个表达求和概念本身的过程，而不仅仅是计算特定和的过程。我们可以在过程式语言中轻松做到这一点，方法是采用上面展示的通用模板，并将“空位”转换为形式参数：

(define (sum term a next b)
  (if (> a b)
      0
      (+ (term a)
         (sum term (next a) next b))))

注意sum接受下界和上界a和b以及过程term和next作为参数。我们可以像使用任何过程一样使用sum。例如，我们可以用它（连同将其参数增加1的过程inc）来定义sum-cubes：

(define (inc n) (+ n 1))

(define (sum-cubes a b)
  (sum cube a inc b))

利用这一点，我们可以计算从1到10的整数的立方之和：

(sum-cubes 1 10)
3025

借助一个计算项的恒等过程，我们可以用sum来定义sum-integers：

(define (identity x) x)

(define (sum-integers a b)
  (sum identity a inc b))

然后我们可以将从1到10的整数相加：

(sum-integers 1 10)
55

我们也可以用同样的方式定义pi-sum：50

(define (pi-sum a b)
  (define (pi-term x)
    (/ 1.0 (* x (+ x 2))))
  (define (pi-next x)
    (+ x 4))
  (sum pi-term a pi-next b))

利用这些过程，我们可以计算 π 的近似值：

(* 8 (pi-sum 1 1000))
3.139592655589783

一旦我们有了sum，就可以将它作为构建进一步概念的构件。例如，函数 f 在积分限 a 和 b 之间的定积分可以用公式 ∫ a b f = [ f ( a + d x 2 ) + f ( a + d x + d x 2 ) + f ( a + 2 d x + d x 2 ) + … ] d x 在 d x 取小值时进行数值近似。我们可以直接将其表达为一个过程：

(define (integral f a b dx)
  (define (add-dx x) (+ x dx))
  (* (sum f (+ a (/ dx 2.0)) add-dx b) 
     dx))

(integral cube 0 1 0.01)
.24998750000000042

(integral cube 0 1 0.001)
.249999875000001

（cube在0和1之间的积分的精确值是1/4。）

1.3.2使用 Lambda 构造过程

在如 1.3.1 那样使用 sum 时，为了能把像 pi-term 和 pi-next 这样平凡的过程用作高阶过程的参数而不得不定义它们，似乎非常别扭。与其定义 pi-next 和 pi-term，更方便的是有一种方式直接指定“返回其输入加 4 的过程”和“返回其输入与（其输入加 2）的乘积的倒数的过程”。我们可以通过引入特殊形式 lambda 来做到这一点，它创建过程。使用 lambda，我们可以把我们想要的东西描述为

(lambda (x) (+ x 4))

和

(lambda (x) (/ 1.0 (* x (+ x 2))))

然后我们的 pi-sum 过程就可以在不定义任何辅助过程的情况下表达为

(define (pi-sum a b)
  (sum (lambda (x) (/ 1.0 (* x (+ x 2))))
       a
       (lambda (x) (+ x 4))
       b))

再次使用 lambda，我们可以编写 integral 过程，而不必定义辅助过程 add-dx：

(define (integral f a b dx)
  (* (sum f (+ a (/ dx 2.0))
            (lambda (x) (+ x dx))
            b)
     dx))

一般来说，lambda 用于创建过程的方式与 define 相同，只是没有为过程指定名称：

(lambda (⟨formal-parameters⟩) ⟨body⟩)

所得的过程与使用 define 创建的过程一样是一个过程。唯一的区别是它没有与环境中的任何名称相关联。事实上，

(define (plus4 x) (+ x 4))

等价于

(define plus4 (lambda (x) (+ x 4)))

我们可以如下解读一个 lambda 表达式：

(lambda                     (x)     (+   x     4))
    |                        |       |   |     |
the procedure of an argument x that adds x and 4

像任何以过程为值的表达式一样，lambda 表达式可以用作组合式中的运算符，例如

((lambda (x y z) (+ x y (square z))) 1 2 3)
12

或者更一般地说，在我们通常使用过程名的任何上下文中。53

使用 let 创建局部变量

lambda 的另一个用途是创建局部变量。我们的过程中经常需要除作为形参绑定的变量之外的局部变量。例如，假设我们希望计算函数 f ( x , y ) = x ( 1 + x y ) 2 + y ( 1 − y ) + ( 1 + x y ) ( 1 − y ) , ，我们也可以将其表示为 a = 1 + x y , ( x , y ) b = 1 − y , f ( x , y ) = x a 2 + y b + a b . 在编写计算 f 的过程时，我们希望不仅把 x 和 y 作为局部变量，还把像 a 和 b 这样的中间量的名称也作为局部变量。实现这一点的一种方法是使用辅助过程来绑定局部变量：

(define (f x y)
  (define (f-helper a b)
    (+ (* x (square a))
       (* y b)
       (* a b)))
  (f-helper (+ 1 (* x y)) 
            (- 1 y)))

当然，我们可以使用 lambda 表达式来指定一个匿名过程以绑定我们的局部变量。f 的主体于是变成对该过程的单次调用：

(define (f x y)
  ((lambda (a b)
     (+ (* x (square a)) 
        (* y b) 
        (* a b)))
   (+ 1 (* x y))
   (- 1 y)))

这种构造如此有用，以至于有一种称为 let 的特殊形式来使其使用更方便。使用 let，f 过程可以写成

(define (f x y)
  (let ((a (+ 1 (* x y)))
        (b (- 1 y)))
    (+ (* x (square a))
       (* y b)
       (* a b))))

let 表达式的一般形式是

(let ((⟨var₁⟩ ⟨exp₁⟩)
      (⟨var₂⟩ ⟨exp₂⟩)
      …
      (⟨varₙ⟩ ⟨expₙ⟩))
  ⟨body⟩)

这可以看作是在说

let ⟨var₁⟩ have the value ⟨exp₁⟩ and
    ⟨var₂⟩ have the value ⟨exp₂⟩ and
    …
    ⟨varₙ⟩ have the value ⟨expₙ⟩
  in ⟨body⟩

let 表达式的第一部分是一个名字-表达式对的表。当求值 let 时，每个名字都与相应表达式的值相关联。let 的主体在这些名字作为局部变量绑定的情况下求值。其实现方式是，let 表达式被解释为以下形式的另一种语法：

((lambda (⟨var₁⟩ … ⟨varₙ⟩)
   ⟨body⟩)
 ⟨exp₁⟩
 …
 ⟨expₙ⟩)

为了提供局部变量，解释器中不需要任何新机制。let 表达式只是底层 lambda 应用的一种语法糖。

从这个等价关系可以看出，由 let 表达式指定的变量的作用域是 let 的主体。这意味着：

  • Let 允许人们尽可能地将变量绑定在靠近其使用位置的地方。例如，如果 x 的值是 5，则表达式的值
    (+ (let ((x 3))
     (+ x (* x 10)))
   x)

    是 38。这里，let 主体中的 x 是 3，所以 let 表达式的值是 33。另一方面，作为最外层 + 的第二个参数的 x 仍然是 5。

  • 变量的值是在 let 之外计算的。当为局部变量提供值的表达式依赖于与局部变量本身同名的变量时，这一点很重要。例如，如果 x 的值是 2，则表达式
    (let ((x 3)
      (y (+ x 2)))
  (* x y))

    的值将是 12，因为在 let 的主体内部，x 将是 3，而 y 将是 4（即外层 x 加上 2）。

有时我们可以使用内部定义来获得与 let 相同的效果。例如，我们可以将上面的过程 f 定义为

(define (f x y)
  (define a 
    (+ 1 (* x y)))
  (define b (- 1 y))
  (+ (* x (square a))
     (* y b)
     (* a b)))

然而，在这种情况下我们更倾向于使用 let，而仅对内部过程使用内部 define。54

1.3.3过程作为通用方法

我们在 1.1.4 中引入了复合过程，作为一种抽象数值运算模式以使它们独立于所涉及的具体数的机制。借助高阶过程，例如 1.3.1 的 integral 过程，我们开始看到一种更强大的抽象：用于表达通用计算方法的过程，独立于所涉及的具体函数。在本节中，我们讨论两个更精细的例子——求函数零点和不动点的通用方法——并展示这些方法如何能直接表达为过程。

用半区间法求方程的根

半区间法是一种简单但强大的技术，用于求方程 f ( x ) = 0 的根，其中 f 是连续函数。其思想是，如果给定点 a 和 b 使得 f ( a ) < 0 < f ( b ) ，那么 f 在 a 和 b 之间必定至少有一个零点。为了定位一个零点，令 x 为 a 和 b 的平均值，并计算 f ( x ) 。如果 f ( x ) > 0 ，那么 f 在 a 和 x 之间必定有一个零点。如果 f ( x ) < 0 ，那么 f 在 x 和 b 之间必定有一个零点。以这种方式继续，我们可以确定越来越小的区间，在这些区间上 f 必定有一个零点。当我们达到区间足够小的点时，过程停止。由于在过程的每一步中不确定区间都减半，所需的步数按 Θ ( log ⁡ ( L / T ) ) 增长，其中 L 是原始区间的长度，而 T 是误差容限（即我们将视为“足够小”的区间大小）。下面是一个实现此策略的过程：

(define (search f neg-point pos-point)
  (let ((midpoint 
         (average neg-point pos-point)))
    (if (close-enough? neg-point pos-point)
        midpoint
        (let ((test-value (f midpoint)))
          (cond 
           ((positive? test-value)
            (search f neg-point midpoint))
           ((negative? test-value)
            (search f midpoint pos-point))
           (else midpoint))))))

我们假设最初给定函数 f 以及其值为负和为正的点。我们首先计算两个给不动点的中点。接着我们检查给定区间是否足够小，如果是，我们就简单地返回中点作为答案。否则，我们计算 f 在中点处的值作为测试值。如果测试值为正，则我们用从原来函数值为负的点到中点的新区间继续该过程。如果测试值为负，我们用从中点到函数值为正的点的区间继续。最后，还有一种可能是测试值为 0，在这种情况下中点本身就是我们要寻找的根。

为了测试端点是否“足够接近”，我们可以使用一个类似于 1.1.7 中用于计算平方根的过程：55

(define (close-enough? x y) 
  (< (abs (- x y)) 0.001))

Search 直接使用起来很别扭，因为我们可能不小心给它提供 f 的值不具有所需符号的点，在这种情况下我们会得到错误的答案。相反，我们将通过以下过程使用 search，该过程检查哪个端点的函数值为负、哪个为正，并相应地调用 search 过程。如果函数在两个给不动点上具有相同的符号，则无法使用半区间法，在这种情况下该过程发出错误信号。56

(define (half-interval-method f a b)
  (let ((a-value (f a))
        (b-value (f b)))
    (cond ((and (negative? a-value) 
                (positive? b-value))
           (search f a b))
          ((and (negative? b-value) 
                (positive? a-value))
           (search f b a))
          (else
           (error "Values are not of 
                   opposite sign" a b)))))

下面的例子使用半区间法来近似 π ，作为 sin ⁡ x = 0 在 2 和 4 之间的根：

(half-interval-method sin 2.0 4.0)
3.14111328125

这是另一个例子，使用半区间法在 1 和 2 之间搜索方程 x 3 − 2 x − 3 = 0 的根：

(half-interval-method 
 (lambda (x) (- (* x x x) (* 2 x) 3))
 1.0
 2.0)
1.89306640625
求函数的不动点

如果 x 满足方程 f ( x ) = x ，数 x 就称为函数 f 的一个不动点。对于某些函数 f ，我们可以从一个初始猜测开始，反复应用 f ， f ( x ) , f ( f ( x ) ) , f ( f ( f ( x ) ) ) , … , 直到数值的变化很小，以此找到一个不动点。利用这个想法，我们可以设计一个过程fixed-point，以一个函数和一个初始猜测作为输入，产生该函数的一个不动点的近似值。我们反复应用这个函数，直到找到两个相邻的值，它们的差小于某个规定的容差：

(define tolerance 0.00001)

(define (fixed-point f first-guess)
  (define (close-enough? v1 v2)
    (< (abs (- v1 v2)) 
       tolerance))
  (define (try guess)
    (let ((next (f guess)))
      (if (close-enough? guess next)
          next
          (try next))))
  (try first-guess))

例如，我们可以用这个方法近似余弦函数的不动点，从 1 作为初始近似值开始：57

(fixed-point cos 1.0)
.7390822985224023

类似地，我们可以找到方程 y = sin ⁡ y + cos ⁡ y 的一个解：

(fixed-point (lambda (y) (+ (sin y) (cos y)))
             1.0)
1.2587315962971173

不动点过程让人想起我们在 1.1.7 中用于求平方根的过程。两者都基于反复改进猜测直到结果满足某个准则的想法。事实上，我们可以很容易地把平方根计算表述为不动点搜索。计算某个数 x 的平方根需要找到一个 y 使得 y 2 = x 。把这个方程写成等价形式 y = x / y ，我们认识到我们是在寻找函数 y ↦ x / y 的不动点58，因此我们可以尝试这样计算平方根：

(define (sqrt x)
  (fixed-point (lambda (y) (/ x y))
               1.0))

不幸的是，这个不动点搜索不收敛。考虑一个初始猜测 y 1 。下一个猜测是 y 2 = x / y 1 ，再下一个猜测是 y 3 = x / y 2 = x / ( x / y 1 ) = y 1 。这导致一个无限循环，其中两个猜测 y 1 和 y 2 反复重复，在答案附近振荡。

控制这种振荡的一种方法是防止猜测变化太大。由于答案总是介于我们的猜测 y 和 x / y 之间，我们可以通过将 y 与 x / y 取平均，来做出一个离 y 不像 x / y 那么远的新猜测，使得 y 之后的下一个猜测是 1 2 ( y + x / y ) 而不是 x / y 。做出这样一系列猜测的过程就是寻找 y ↦ 1 2 ( y + x / y ) 的不动点的过程：

(define (sqrt x)
  (fixed-point 
   (lambda (y) (average y (/ x y)))
   1.0))

（注意， y = 1 2 ( y + x / y ) 是方程 y = x / y ; 的一个简单变换，要推导它，在方程两边加上 y 并除以 2。）

经过这一修改，平方根过程就可以工作了。事实上，如果展开这些定义，就可以看出，这里产生的平方根近似值序列，与我们在1.1.7中最初的平方根过程所产生的序列完全相同。这种对解的逐次近似值取平均的方法，我们称为平均阻尼，它常常有助于不动点搜索的收敛。

1.3.4作为返回值的过程

上面的例子展示了将过程作为参数传递的能力如何显著增强我们编程语言的表达能力。通过创建其返回值本身也是过程的过程，我们可以获得更强的表达能力。

我们可以通过再次考察在1.3.3末尾描述的不动点示例来说明这一思想。我们将平方根过程的新版本表述为不动点搜索，从观察到 x 是函数 y ↦ x / y 的一个不动点开始。然后我们使用平均阻尼来使近似值收敛。平均阻尼本身是一种有用的通用技术。即，给定一个函数 f ，我们考虑这样一个函数，它在 x 处的值等于 x 和 f ( x ) 的平均值。

我们可以通过以下过程来表达平均阻尼的思想：

(define (average-damp f)
  (lambda (x) 
    (average x (f x))))

Average-damp是一个过程，它接受一个过程f作为参数，并返回一个过程（由lambda产生）作为其值，该过程在应用于一个数x时，产生x和(f x)的平均值。例如，将average-damp应用于square过程会产生一个过程，其在某个数 x 处的值是 x 和 x 2 的平均值。将这个结果过程应用于10返回10和100的平均值，即55：59

((average-damp square) 10)
55

使用average-damp，我们可以将平方根过程重新表述如下：

(define (sqrt x)
  (fixed-point 
   (average-damp 
    (lambda (y) (/ x y)))
   1.0))

注意这种表述如何明确地体现了该方法中的三个思想：不动点搜索、平均阻尼和函数 y ↦ x / y 。将这种平方根方法的表述与1.1.7中给出的原始版本进行比较是有启发性的。请记住，这些过程表达的是同一个计算过程，并注意当我们用这些抽象来表达该过程时，思想变得清晰了多少。一般来说，将计算过程表述为过程有许多方式。有经验的程序员知道如何选择特别清晰的过程表述，并且将计算过程中有用的元素作为可以复用于其他应用的独立实体暴露出来。作为一个简单的复用示例，注意 x 的立方根是函数 y ↦ x / y 2 的一个不动点，因此我们可以立即将我们的平方根过程推广为一个提取立方根的过程：60

(define (cube-root x)
  (fixed-point 
   (average-damp 
    (lambda (y) 
      (/ x (square y))))
   1.0))
牛顿法

当我们在1.1.7中首次引入平方根过程时，我们提到这是牛顿法的一个特例。如果 x ↦ g ( x ) 是一个可微函数，那么方程 g ( x ) = 0 的一个解是函数 x ↦ f ( x ) 的一个不动点，其中 f ( x ) = x − g ( x ) D g ( x ) ，而 D g ( x ) 是 g 在 x 处的导数。牛顿法是使用我们上面看到的不动点方法来通过寻找函数 f 的不动点来近似方程的解。61

对于许多函数 g 以及对于足够好的 x 初始猜测，牛顿法会非常迅速地收敛到 g ( x ) = 0 的一个解。62

为了将牛顿法实现为一个过程，我们必须首先表达导数的概念。注意，“导数”和平均阻尼一样，是将一个函数变换为另一个函数的东西。例如，函数 x ↦ x 3 的导数是函数 x ↦ 3 x 2 。一般来说，如果 g 是一个函数，而 d x 是一个小的数，那么 g 的导数 D g 是这样一个函数，它在任意数 x 处的值（在 d x 趋于零的极限下）由 D g ( x ) = g ( x + d x ) − g ( x ) d x . 给出。因此，我们可以将导数的概念（取 d x 为，比如说，0.00001）表达为过程

(define (deriv g)
  (lambda (x)
    (/ (- (g (+ x dx)) (g x))
       dx)))

连同定义

(define dx 0.00001)

与average-damp一样，deriv是一个过程，它接受一个过程作为参数并返回一个过程作为值。例如，为了近似 x ↦ x 3 在5处的导数（其精确值为75），我们可以求值

(define (cube x) (* x x x))

((deriv cube) 5)
75.00014999664018

借助deriv，我们可以将牛顿法表达为一个不动点过程：

(define (newton-transform g)
  (lambda (x)
    (- x (/ (g x) 
            ((deriv g) x)))))

(define (newtons-method g guess)
  (fixed-point (newton-transform g) 
               guess))

newton-transform过程表达了本节开头的公式，而newtons-method可以很容易地基于它来定义。它接受一个计算我们想要求零点的函数的过程，以及一个初始猜测作为参数。例如，为了求 x 的平方根，我们可以使用牛顿法来求函数 y ↦ y 2 − x 的零点，从初始猜测1开始。63

这提供了平方根过程的又一种形式：

(define (sqrt x)
  (newtons-method 
   (lambda (y) 
     (- (square y) x)) 
   1.0))
抽象与一等过程

我们已经看到了两种将平方根计算表达为更一般方法实例的方式，一次作为不动点搜索，一次使用牛顿法。由于牛顿法本身被表达为不动点过程，我们实际上看到了两种将平方根计算为不动点的方式。每种方法都从一个函数开始，并找到该函数的某种变换的不动点。我们可以将这个一般思想本身表达为一个过程：

(define (fixed-point-of-transform 
         g transform guess)
  (fixed-point (transform g) guess))

这个非常一般的过程接受一个计算某个函数的过程g、一个变换g的过程以及一个初始猜测作为参数。返回的结果是变换后函数的不动点。

使用这个抽象，我们可以将本节中的第一个平方根计算（其中我们寻找 y ↦ x / y 的平均阻尼版本的不动点）重新表述为这个一般方法的一个实例：

(define (sqrt x)
  (fixed-point-of-transform 
   (lambda (y) (/ x y))
   average-damp
   1.0))

类似地，我们可以将本节中的第二个平方根计算（牛顿法的一个实例，它寻找 y ↦ y 2 − x 的牛顿变换的不动点）表达为

(define (sqrt x)
  (fixed-point-of-transform 
   (lambda (y) (- (square y) x))
   newton-transform
   1.0))

我们在1.3节开头观察到，复合过程是一种关键的抽象机制，因为它们允许我们将一般的计算方法表达为编程语言中的显式元素。现在我们已经看到了高阶过程如何允许我们操纵这些一般方法来创建进一步的抽象。

作为程序员，我们应当对发现程序中底层抽象的机会保持警觉，并在此基础上构建和泛化它们，以创建更强大的抽象。这并不是说人们应该总是以尽可能抽象的方式编写程序；专家级程序员知道如何选择适合其任务的抽象层次。但重要的是能够以这些抽象来思考，这样我们才能准备好将它们应用于新的情境。高阶过程的意义在于，它们使我们能够将这些抽象显式地表示为编程语言中的元素，从而可以像处理其他计算元素一样处理它们。

一般来说，编程语言对计算元素可以被操作的方式施加了限制。限制最少的元素被认为具有一等地位。一等元素的一些“权利和特权”包括：64

  • 它们可以由变量命名。
  • 它们可以作为参数传递给过程。
  • 它们可以作为过程的结果返回。
  • 它们可以包含在数据结构中。65

与其他常见编程语言不同，Lisp 赋予过程完全的一等地位。这对高效实现提出了挑战，但由此带来的表达能力的提升是巨大的。66
